# TypeScript

Read with `SKILL.md` when the project is written in TypeScript. There are no
templates here yet; build the skeleton from the rules in `SKILL.md`.

## Defaults (change them when the purpose calls for it)

| Area | Default |
| --- | --- |
| Runtime | Bun |
| Frontend | SolidJS + Vite; Astro or others when the purpose fits better |

## Rules

- Package versions come from the npm registry (or JSR).
- npm is published to through trusted publishing; no token is stored.
